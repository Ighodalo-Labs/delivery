# Delivery

This is where we track every deliverable at Ighodalo Labs. One place. Everyone can see where things stand. No one has to chase anyone or explain themselves.

## What a milestone is

A milestone is one agreed unit of work. It has an owner, a due date and a clear definition of done. We agree the date together before work starts. If a date looks too tight, say so before we lock it.

Create one with **Issues > New issue > Milestone**. It is added to the project board automatically.

## How pay works

- **Base fee.** Paid when the milestone passes its definition of done. Always.
- **On-Time Bonus.** Paid on top when the milestone is submitted by the agreed date and passes the first check.

The bonus never replaces the base fee. Missing the bonus does not reduce the base fee.

## The clock

- The clock starts on the agreed start date.
- The clock stops when the owner moves the item to **Ready for check** and fills in **Submitted on**. Review time on our side never counts against you.
- If Labs causes a delay (late access, late answers, a scope change), the clock pauses. Add a comment with the reason, add the label `clock:paused`, and record the days in **Clock paused days**. The agreed date moves by those days.
- Once the date is agreed it stays fixed. If it needs to change, write the reason in a comment first.

## Statuses

| Status | Meaning | Who moves it |
| --- | --- | --- |
| Backlog | Not agreed yet. No date. | Anyone |
| Agreed | Scope and date agreed by both sides. | Studio Lead |
| In progress | The owner is working on it. | Owner |
| Ready for check | Submitted. Waiting for review. | Owner |
| Done | Passed the definition of done. | Studio Lead, after the check |
| Blocked | Cannot move. Reason is in a comment. | Anyone |

## First check

The reviewer follows the steps in **How it will be checked**. The result goes in the **First check** field: Pass or Rework needed. A pass on the first check, submitted by the agreed date, earns the On-Time Bonus. If rework is needed, the base fee is still paid once it passes.

## Fields

Venture, Reward type, Priority, Start date, Target date (the agreed due date), Original due date (never edited), Agreed on, Submitted on, Clock paused days, First check, On-Time Bonus, Effort, Evidence (a link that proves it is done).

## Good milestones

- Small. Two weeks at most.
- Every line in the definition of done can be tested with yes or no.
- One owner.
